# Examples

- `samples/` contains synthetic images generated by
  [`../tools/generate_synthetic_samples.py`](../tools/generate_synthetic_samples.py).
  They contain no real personal data: the holder, the issuing state (`ZZT`) and
  every credential number are fabricated.
- `output/` is intended for generated JSON responses and is ignored by Git.

Processing a sample needs an ONNX model directory; see
[`../docs/models.md`](../docs/models.md).

Run the CLI against a sample:

```bash
IDENTITY_ANALYSIS_ASSETS=assets identity-document \
  examples/samples/synthetic_id_back.jpg \
  --output examples/output/back.json
```

Run the HTTP service and submit the same image:

```bash
docker build -t identity-analysis .
docker run --rm -p 8000:8000 -v "$PWD/assets:/app/assets:ro" identity-analysis

curl -X POST http://localhost:8000/v1/ocr \
  -F 'image=@examples/samples/synthetic_id_back.jpg'
```

Regenerate the fixtures with:

```bash
python tools/generate_synthetic_samples.py
python tools/generate_test_catalog.py
```
